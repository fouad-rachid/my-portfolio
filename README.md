- Responsive design for all devices
- Fast development with Vite
- Modern UI/UX
- Project showcase section
- Skills & technologies section
- Contact section
- Smooth navigation and animations

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- HTML5
- CSS3
